# ビー玉コレクション

小学校高学年向けの、目標達成を応援するシンプルなWebアプリです。

## 使い方

1. `index.html` をブラウザーで開きます。
2. 「設定を変更する」から項目、ビー玉数、色、目標数を編集します。
3. 「やることをみる」で「達成！」を押すとビー玉が増えます。
4. 100個（設定した目標数）で達成画面になり、次は1個から始まります。

設定と進み具合はブラウザーの localStorage に保存されます。サーバーやデータベースは不要です。

## GitHub Pages

このフォルダーの中身をGitHubリポジトリへ追加し、リポジトリの Settings > Pages から公開元を選ぶと公開できます。
